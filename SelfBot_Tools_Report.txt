================================================================================
COORDINATE SYSTEM (Desktop Tools)
================================================================================

All coordinate-using desktop tools share a unified pipeline:

  1. screenshot captures a display -> resized to API limit (1568px / 1.15MP)
  2. _screenshot_scale  = logical_pixels / image_pixels
  3. _screenshot_offset = (display_origin_x, display_origin_y)
  4. _screenshot_dims   = (image_width, image_height)

  Image coord -> Screen coord:  round(img_coord * scale) + offset
  Screen coord -> Image coord:  round((screen_coord - offset) / scale)

  mouse_click additionally clamps coordinates to _screenshot_dims bounds,
  emitting a warning if the model sends out-of-range values.
