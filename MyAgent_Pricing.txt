================================================================================
  NOTES
================================================================================

  - Prices are matched by longest model-name prefix. For example, the model
    "claude-opus-4-6-20250414" matches "claude-opus-4-6" (not "claude-opus-4").

  - Models not matching any prefix will show no cost line in the output.

  - Anthropic cache pricing uses the 5-minute cache write multiplier (1.25x
    base input). There is also a 1-hour cache write at 2x base input, but
    MyAgent uses the default 5-minute TTL.

  - OpenAI server-side web search costs $10 per 1,000 searches (not tracked
    in token-based cost display).

  - This file is auto-generated from the ANTHROPIC_PRICING, OPENAI_PRICING,
    GEMINI_PRICING, and XAI_PRICING tables in myagent/constants.py.

  - To update pricing: edit the tables in myagent/constants.py and regenerate
    this file.
