  OpenAI reasoning/thinking tokens are billed at the output token rate
  (they are already INSIDE usage.output_tokens — no separate bucket, unlike
  Gemini's thoughts_token_count).
  Server-side web search has an additional per-search charge (not tracked).

  CACHED INPUT (added 2026-07-31): OpenAI caches automatically above ~1024
  tokens — no client opt-in, unlike Anthropic — so the discount always hit the
  bill; it just wasn't reported here, which OVERSTATED every OpenAI line in
  APICostLog.txt. Cached input is 1/10 of input on the GPT-5 families and 1/4
  on GPT-4.1; the -pro tiers (gpt-5.5-pro / gpt-5.2-pro / gpt-5-pro) have NO
  cached tier. Cache WRITES are free (no column on the pricing page), unlike
  Anthropic's 1.25x. Tracked via input_tokens_details.cached_tokens, which is a
  SUBSET of input_tokens and so is subtracted before pricing.

  2026-07-31 RATE AUDIT — eight entries were wrong and are corrected below:
  gpt-5.2, gpt-5.2-pro, gpt-5.1, gpt-4.1-mini, gpt-4.1-nano and codex-mini all
  sat at exactly HALF the Standard rate (Batch-tier numbers); gpt-5.6-terra
  carried gpt-5.4's numbers; gpt-5.6-luna was 5x too high.
  2026-08-25 RATE AUDIT — gpt-5.6-sol was carrying gpt-5.5's $5/$30; it bills
  $4/$20 (cached $0.40), corrected below. The 5.5/5.6 tiers bill 2x input /
  1.5x output above 272K input tokens (table keeps the ≤272K tier). All three
  5.6 tiers accept reasoning.effort "max" (5.5 / 5.4 reject it) — MyAgent's
  Reasoning combobox offers Max on 5.6+.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Provider "Google" in MyAgent's picker (the company; the models are branded
  gemini-*). Gemini has a free tier (under rate limits). Prices below are
  paid tier.

  THINKING TOKENS bill at the OUTPUT rate but are NOT inside
  candidates_token_count — they are their own bucket, thoughts_token_count.
  (Corrected 2026-07-31; this file previously claimed they were included, and
  the code read only candidates, UNDER-reporting every thinking-enabled run.
  Verified live on gemini-3.5-flash: prompt 15009 + candidates 1 + thoughts
  133 = total 15143.)

  CACHED INPUT (added 2026-07-31): Gemini's IMPLICIT caching is automatic on
  the 2.5+ tiers — no client opt-in, unlike Anthropic — so the discount always
  hit the bill; it just wasn't reported, which OVERSTATED every Google line in
  APICostLog.txt. Cached input is exactly 1/10 of input across the Gemini 3
  family. Reported as usage_metadata.cached_content_token_count, a SUBSET of
  prompt_token_count, so it is subtracted before pricing. The hit only appears
  above the model's implicit-cache floor — 4,096 tokens on the Gemini 3 tiers,
  2,048 on 2.5 — so a zero on short prompts is normal, not a broken probe.
  Context-cache STORAGE ($1.00/M tokens/hour) is NOT modelled: it applies to
  EXPLICIT CachedContent objects, which MyAgent never creates.
