# desktop_launchers/

`desktop_launchers/` — Cross-platform "Desktop shortcut with a custom icon" sources: macOS AppleScript apps (compiled per-machine by `rebuild.sh`) and their Windows twins `UnreadSummary_Win.ps1` / `CSVEditor_Win.ps1` / `MyAgent_Win.ps1` / `SelfBot_Win.ps1` / `MyBackup_Win.ps1` (plus two Task Scheduler jobs rather than shortcuts — `Heartbeat_Listener_Win.ps1`, 2026-10-26: `-Register` once creates `MyAgent_Heartbeat_Listener`, the venv's windowless `pythonw.exe Heartbeat.py --listen` at logon — and, since 2026-11-05, every 10 minutes whenever it is not running, the restart the 1-minute restart setting never was for a process that exited by itself — with no time limit, and starts it — no conhost needed, pythonw has no console; and `ProtonBridge_Watchdog_Win.ps1` — `-Register` once; restarts Proton Bridge's launcher if `bridge.exe` is gone, at logon +2 min and every 15 min; its action runs under `conhost.exe --headless`, not `powershell -WindowStyle Hidden`, which flashed a Windows Terminal window on every check because a console program's window exists before PowerShell parses the switch — the hidden click launchers' Desktop shortcuts target the same `conhost.exe --headless powershell.exe …` for the same reason since 2026-09-03, `TodoList.lnk` wrapping its batch file in `cmd.exe /c`; only the two visible log viewers target `powershell.exe` directly), with `icon_*.ico` rendered from the 1024px `icon_*_master.png` artwork. `CSVEditor_Win.ps1` and `MyBackup_Win.ps1` are launch-or-focus (an already-open window comes to the front instead of a second copy starting — load-bearing for MyBackup, since two instances could mirror into the same TO directory at once); `MyAgent_Win.ps1` and `SelfBot_Win.ps1` always launch a fresh instance (both are multi-instance by design — SelfBot's second instance self-chats with the first, and SelfBot.py cascades it by `CASCADE_OFFSET` px so the two windows don't stack on the same saved geometry). The `My Agent.app` / `MyAgent_Win.ps1` robot icon (`icon_myagent_master.png`) is the macOS/Windows-matched twin of the legacy repo-root `myagent.ico`. The `SelfBot` icon (`icon_selfbot_master.png`, from `make_selfbot_icon.py`) is an anxious cross-eyed googly robot recursively contemplating a smaller copy of itself inside its own thought bubble — SelfBot's duo self-chat rendered as a self-referential Droste. The `MyBackup` icon (`icon_mybackup_master.png`, from `make_mybackup_icon.py`, 2026-10-03) is the family's one sober design, by the user's request — two drive slabs on a slate-blue tile, the TO drive's light green, a broad down-arrow between them for the one-way mirror; no googly eyes. The `general` icon (`icon_general_master.png`, from `make_general_icon.py`, 2026-11-02) is the one icon of a plain FOLDER shortcut, not a launcher — the Desktop `general.lnk` targets `<OneDrive>\MyAppShare\general` and Explorer opens it directly, no `.ps1` twin and no conhost — a manila folder with googly eyes over the flap and a cloud for the OneDrive share. The **Bank Credentials** launcher (2026-11-09: `BankCredentials_Win.ps1`; `BankCredentials.applescript` + `store_bank_credentials.command` on the Mac; icon `icon_bankcredentials_master.png` from `make_bankcredentials_icon.py` — a safe with googly eyes on its round door, a spoked dial and a golden key) is the third VISIBLE console beside the two log viewers, and must stay one: it shows each bank login's vault state (stored / missing) and runs the chosen skill's own helper — westpac-login's `windows_login_support.py` / `macos_login_support.py`, anz-login's `anz_login_support.py`, cba-login's `cba_login_support.py` — in `store-credentials` mode, whose `getpass` prompts need a real console and refuse a redirected stdin, so the Windows shortcut targets `powershell.exe` directly (never `conhost.exe --headless`) and the Mac app opens Terminal on the `.command` (TCC-free, like the viewers); the launcher never sees a value, the skills folder comes from `myagent.datapaths.resolve_skills_dir`, and `-Status` prints the three states non-interactively. Built `.app`s and Desktop `.lnk`s are per-machine and NOT committed; full details in `desktop_launchers/README.md`
