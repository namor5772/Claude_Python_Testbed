19. PRESS_KEY
    ⚠️  WINDOWS SPECIFIC - KEY MODIFIERS DIFFER
    Description: Press a key or key combination.
    
    Windows Key Modifiers:
    - ctrl   (CONTROL) - Main modifier key, NOT command!
    - alt    (ALT) - Alt key
    - shift  (SHIFT) - Shift key
    - win    (WINDOWS) - Windows logo key
    
    Windows Examples:
    - 'ctrl+c'        → Copy (NOT command+c!)
    - 'ctrl+v'        → Paste (NOT command+v!)
    - 'ctrl+z'        → Undo
    - 'ctrl+shift+s'  → Snip & Sketch screenshot
    - 'alt+tab'       → Switch applications
    - 'win+v'         → Clipboard history (Windows 10/11)
    - 'win+shift+s'   → Screenshot to clipboard
    - 'ctrl+a'        → Select all
    - 'ctrl+f'        → Find
    - 'alt+f4'        → Close window/application
    - 'win+e'         → Open File Explorer
    - 'win+d'         → Show desktop
    - 'ctrl+alt+del'  → Task Manager / Lock screen
    
    ⚠️  CRITICAL: Never use 'command' on Windows - always use 'ctrl' or 'alt'

20. OPEN_APPLICATION
    ⚠️  WINDOWS SPECIFIC - USES 'Start-Process' POWERSHELL SYNTAX
    Description: Open an application by common name or full path.
    
    Windows PowerShell Syntax: Start-Process "Application Name"
    
    Windows Examples:
    - notepad
    - notepad++
    - calc (Calculator)
    - explorer (File Explorer)
    - cmd (Command Prompt)
    - powershell
    - mspaint (Paint)
    - chrome
    - firefox
    - msedge (Microsoft Edge)
    - code (Visual Studio Code)
    - excel
    - winword (Microsoft Word)
    - spotify
    - discord
    - slack
    
    With Arguments (open file with app):
    - notepad C:\Users\username\file.txt
    - "C:\Program Files\Microsoft VS Code\Code.exe" C:\Projects\folder
    
    Full Paths (if application not in PATH):
    - "C:\Program Files\Google\Chrome\Application\chrome.exe"
    - "C:\Program Files\Microsoft VS Code\Code.exe"
    - "C:\Program Files\Notepad++\notepad++.exe"
    
    Known Windows Applications:
    chrome, firefox, edge, notepad, notepad++, calculator, terminal,
    excel, word, vscode, spotify, discord, slack, teams
    
    Note: Notepad is available on Windows (N/A on macOS)

21. FIND_WINDOW
    Description: Find windows matching a title pattern.

22. WAIT_FOR_WINDOW

25. RUN_COMMAND
    ⚠️  WINDOWS SPECIFIC - RUNS POWERSHELL
    Description: Execute a command on the local machine and return output.
    
    Windows Shell: PowerShell (default)
    
    Windows File Path Format: C:\Users\username\path\to\file
    NOT: /Users/username/path/to/file (macOS/Unix format)
    
    Windows Command Examples (PowerShell):
    - 'Get-ChildItem'                → List files in directory (dir equivalent)
    - 'Get-Location'                 → Current directory (pwd equivalent)
    - 'New-Item -ItemType Directory -Path "folder"' → Create directory (mkdir)
    - 'Remove-Item file.txt'         → Delete file (del)
    - 'Copy-Item file.txt copy.txt'  → Copy file (copy)
    - 'Move-Item old.txt new.txt'    → Move/rename file (move)
    - 'Get-Content file.txt'         → Display file contents (type)
    - 'Select-String "search" file.txt' → Search in file (findstr)
    - 'Get-Process'                  → List processes (tasklist)
    - 'Stop-Process -ProcessName python' → Kill process (taskkill)
    
    Windows Home Directory Variables:
    - $env:USERPROFILE              → C:\Users\username
    - $env:HOMEPATH                 → \Users\username
    - $env:APPDATA                  → User AppData folder
    - $env:PROGRAMFILES             → Program Files directory
    - $env:TEMP                     → Temporary files directory
    
    Example Path Usage:
    - $env:USERPROFILE\Desktop
    - C:\Users\username\Documents
    - C:\Users\username\Downloads
    - C:\Users\username\Projects
    
    Windows Package Managers (if installed):
    - choco install package_name    → Chocolatey
    - winget install package_name   → Windows Package Manager
    - pip install package_name      → Python pip
    
    Important Windows Commands:
    - 'systeminfo'                  → System information
    - 'Get-Disk'                    → Disk information
    - 'Get-WindowsUpdate'           → Windows Update info
    - 'Get-ComputerInfo'            → Computer details
    
    ⚠️  Windows Admin Commands: Use 'Start-Process -Verb RunAs' for elevated privileges
    Example: 'Start-Process powershell -Verb RunAs'

================================================================================
                   WINDOWS-SPECIFIC BEST PRACTICES
================================================================================

1. FILE PATHS
   ✓ Use backslashes: C:\Users\username\path\to\file
   ✓ Use double backslashes in strings: C:\\Users\\username\\file.txt
   ✓ Use variables: $env:USERPROFILE\Documents\file.txt
   ✗ Never use forward slashes: /Users/username/file (Unix format)

2. KEYBOARD SHORTCUTS
   ✓ Use 'ctrl' for primary modifier, not 'command'
   ✓ Remember: ctrl+c/v, not command+c/v
   ✗ Don't use macOS-style command+key combinations

3. APPLICATION LAUNCHING
   ✓ Use application names directly if in PATH
   ✓ Use full paths for installed applications: "C:\Program Files\...\app.exe"
   ✗ Don't use: open -a (macOS syntax)

4. COMMAND EXECUTION
   ✓ Use PowerShell cmdlets: Get-ChildItem, New-Item, etc.
   ✓ Supports traditional CMD commands: dir, del, copy, etc.
   ✓ Use Write-Host for output: Write-Host "Message"

5. PATHS IN SCRIPTS
   ✓ Use absolute paths: C:\Users\username\Documents\file.txt
   ✓ Use environment variables: $env:USERPROFILE\file.txt
   ✓ Use quotes for paths with spaces: "C:\Program Files\Application\app.exe"

6. PERMISSIONS
   ✓ Use -Verb RunAs for admin tasks: Start-Process -Verb RunAs
   ✓ Use icacls for permission management
   ✓ Check file properties: Get-ItemProperty

================================================================================
                         WINDOWS SPECIAL NOTES
================================================================================

1. POWERSHELL EXECUTION POLICY
   If scripts won't run, you may need to change execution policy:
   - Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

2. LONG PATH SUPPORT
   Windows has 260-character path limit (unless long paths enabled):
   - Enable: reg add HKLM\SYSTEM\CurrentControlSet\Control\FileSystem /v LongPathsEnabled /t REG_DWORD /d 1

3. DRIVE LETTERS
   Remember Windows uses drive letters (C:, D:, E:, etc.):
   - C:\      → Primary drive
   - D:\      → Secondary drive (if present)
   - Network paths: \\servername\sharename

4. ENVIRONMENT VARIABLES
   Common Windows environment variables:
   - %USERPROFILE%  → User home directory
   - %APPDATA%      → Application data folder
   - %TEMP%         → Temporary folder
   - %SYSTEMROOT%   → Windows system directory
   - %PROGRAMFILES% → Program Files directory

5. REGISTRY
   PowerShell can access Windows Registry:
   - Get-ItemProperty -Path "HKLM:\path"
   - Set-ItemProperty -Path "HKLM:\path" -Name "key" -Value "value"
