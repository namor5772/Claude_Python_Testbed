================================================================================
                  MYAGENT.PY - AVAILABLE TOOLS (macOS SPECIFIC)
================================================================================

MyAgent.py on macOS has access to a comprehensive set of tools. This document
highlights macOS-specific implementations, behaviors, and syntax requirements.

================================================================================
                            WEB & BROWSER TOOLS
================================================================================

1. WEB_SEARCH
   Description: Search the web for information using a search query.
   macOS Notes: Platform-independent. Works identically.
   Example: Search for "weather forecast Sydney"

2. FETCH_WEBPAGE
   Description: Retrieve the full content of a specific webpage URL.

3. BROWSER_OPEN

   macOS Notes: Opens Edge or Chrome (macOS default Safari alternative)

5-13. BROWSER TOOLS (CLICK, FILL, GET_TEXT, RUN_JS, SCREENSHOT, CLOSE, WAIT_FOR, SELECT, GET_ELEMENTS)
   macOS Notes: All platform-independent and work identically on macOS.

================================================================================
                    DESKTOP AUTOMATION TOOLS (macOS SPECIFIC)
================================================================================

14. SCREENSHOT
    Description: Take a screenshot of the screen (2560x1440 resolution).
    macOS Path: /Users/[username]/Screenshots/ (typical location)
    Example: Take screenshot of region
    Note: macOS may have different screen resolutions depending on retina display

15. MOUSE_CLICK
    Description: Click the mouse at a given (x, y) position.
    macOS Notes: Coordinates are in screen pixels
    macOS Specific: Use pixel positions as shown in screenshots
    Example: Click at position (640, 360)

16. MOUSE_DRAG
    Description: Drag the mouse from one point to another.
    macOS Notes: Works identically to other platforms
    Example: Drag from (100, 100) to (500, 500)

17. MOUSE_SCROLL
    Description: Scroll the mouse wheel.
    macOS Notes: Works identically to other platforms
    Example: Scroll down 5 clicks

18. TYPE_TEXT
    Description: Type text at the current cursor position.
    macOS Notes: Works identically to other platforms
    Example: Type "Hello World"

19. PRESS_KEY
    ⚠️  MACOS SPECIFIC - KEY MODIFIERS DIFFER
    Description: Press a key or key combination.
    
    macOS Key Modifiers:
    - command  (⌘) - NOT ctrl! This is the Command key
    - option   (⌥) - Alt/Option key
    - shift    (⇧) - Shift key
    - ctrl     (⌃) - Control key (less common on macOS)
    
    macOS Examples:
    - 'command+c'      → Copy (NOT ctrl+c!)
    - 'command+v'      → Paste (NOT ctrl+v!)
    - 'command+z'      → Undo
    - 'command+shift+s' → Screenshot to file
    - 'option+command+i' → Developer tools in browsers
    - 'command+q'      → Quit application
    - 'command+tab'    → Switch applications
    - 'shift+command+3' → Capture full screen
    - 'shift+command+4' → Capture selected area
    
    ⚠️  CRITICAL: Never use 'ctrl+c' for copy on macOS - always use 'command+c'

20. OPEN_APPLICATION
    ⚠️  MACOS SPECIFIC - USES 'open -a' SYNTAX
    Description: Open an application by common name or full path.
    
    macOS Syntax: open -a "Application Name"
    
    macOS Examples:
    - open -a TextEdit
    - open -a Safari
    - open -a "Visual Studio Code"
    - open -a Finder
    - open -a Terminal
    - open -a Calculator
    - open -a Preview
    - open -a Keynote
    - open -a Pages
    - open -a "Google Chrome"
    - open -a Spotify
    - open -a Discord
    - open -a Slack
    
    With Arguments (open file with app):
    - open -a TextEdit /path/to/file.txt
    - open -a "Visual Studio Code" /path/to/project
    
    Known macOS Applications:
    chrome, firefox, edge, safari, notepad (N/A), terminal, finder,
    excel, word, vscode, spotify, discord, slack, teams
    
    Note: Some Windows-only apps (like Notepad) not available on macOS
    Use TextEdit as alternative for plain text editing

21. FIND_WINDOW
    Description: Find windows matching a title pattern.
    macOS Notes: Returns window information for any open macOS window
    Example: Find window with title "Chrome"
    macOS Window Titles: Usually match application names

22. WAIT_FOR_WINDOW
    Description: Wait until a window with given title appears.
    macOS Notes: Polls every 0.5 seconds for window appearance
    Example: Wait for window titled "File Save Dialog"

================================================================================
                      FILE & DATA TOOLS (macOS SPECIFIC)
================================================================================

25. RUN_COMMAND
    ⚠️  MACOS SPECIFIC - RUNS BASH SHELL
    Description: Execute a command on the local machine and return output.
    
    macOS Shell: bash (or zsh on newer macOS)
    
    macOS File Path Format: /Users/username/path/to/file
    NOT: C:\Users\username\path\file (Windows format)
    
    macOS Command Examples:
    - 'ls -la'                    → List files in current directory
    - 'pwd'                       → Print working directory
    - 'mkdir test_folder'         → Create directory
    - 'rm file.txt'               → Delete file
    - 'cp file.txt copy.txt'      → Copy file
    - 'mv old.txt new.txt'        → Move/rename file
    - 'cat file.txt'              → Display file contents
    - 'grep "search" file.txt'    → Search in file
    - 'ps aux | grep python'      → List processes
    - 'which python3'             → Find application path
    - 'open -a TextEdit file.txt' → Open file with app
    
    macOS Home Directory Shortcut: ~
    Examples:
    - ~/Desktop
    - ~/Documents
    - ~/Projects
    - ~/Downloads
    
    macOS Package Managers (if installed):
    - brew install package_name   → Homebrew
    - sudo port install package   → MacPorts
    
    Important macOS Commands:
    - 'softwareupdate -l'         → Check for system updates
    - 'diskutil list'             → List disks
    - 'system_profiler'           → System information
    - 'defaults read'             → Read macOS preferences
    
    ⚠️  macOS Admin Commands: Use 'sudo' prefix for privileged operations
    Example: 'sudo chown -R user /path/to/dir'

26. CSV_SEARCH
    Description: Search a delimited text file for records matching a value.
    macOS Path Format: /Users/username/path/to/file.csv
    Example: Search CSV for "John" in 'Name' column
    macOS Notes: Platform-independent functionality

================================================================================
                  MACOSSPECIFIC BEST PRACTICES
================================================================================

1. FILE PATHS
   ✓ Use forward slashes: /Users/username/path/to/file
   ✓ Use ~ for home directory: ~/Documents/file.txt
   ✗ Never use backslashes: C:\Users\username\file

2. KEYBOARD SHORTCUTS
   ✓ Use 'command' for primary modifier, not 'ctrl'
   ✓ Remember: command+c/v, not ctrl+c/v
   ✗ Don't use Windows-style ctrl+key combinations

3. APPLICATION LAUNCHING
   ✓ Use: open -a "Application Name"
   ✓ Quote app names with spaces: open -a "Visual Studio Code"
   ✗ Don't use: Start-Process (Windows syntax)

4. COMMAND EXECUTION
   ✓ Use bash/zsh syntax
   ✓ Use standard Unix commands: ls, pwd, grep, sed, awk
   ✗ Don't use: Windows PowerShell commands

5. PATHS IN SCRIPTS
   ✓ Use absolute paths: /Users/roman/Projects/file.txt
   ✓ Use relative with ./: ./script.sh
   ✓ Use ~ shortcut: ~/Desktop/file.txt

6. PERMISSIONS
   ✓ Use sudo for admin tasks: sudo chown user file
   ✓ Use chmod for file permissions: chmod +x script.sh
   ✓ Check permissions: ls -l
